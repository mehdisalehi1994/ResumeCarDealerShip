خلاصه پروژه:

یک وب‌سایت استاتیک فروشگاه خودروهای لوکس است که با هدف شبیه‌سازی یک وب‌سایت حرفه‌ای توسعه داده شده است. این پروژه شامل طراحی کاملاً واکنش‌گرا برای موبایل، تبلت و دسکتاپ، منوی برگری برای دستگاه‌های کوچک، لودینگ اولیه صفحه، انیمیشن‌ها و تعاملات CSS، و استفاده از تصاویر و ویدئوهای پس‌زمینه باکیفیت است. ساختار سایت به‌صورت بخش‌بندی‌شده شامل معرفی خودروها، خدمات، گالری، نظرات مشتریان و فرم تماس طراحی شده و پیاده‌سازی آن به‌صورت استاندارد با Bootstrap 4 انجام شده است. این پروژه نشان‌دهنده رشد مهارتی من در پیاده‌سازی صفحات فرانت‌اند، طراحی واکنش‌گرا، استفاده از انیمیشن‌ها و مدیریت محتوای چندرسانه‌ای در سطحی نزدیک به پروژه‌های واقعی وب است.
